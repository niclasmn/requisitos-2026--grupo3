# CDU05 — Verificar Elegibilidade Preliminar

## 1. Nome do Caso de Uso
Verificar Elegibilidade Preliminar

## 2. Objetivo
Permitir que o estudante compare seus dados acadêmicos autodeclarados com os requisitos de uma oportunidade, obtendo uma avaliação orientativa.

## 3. Atores
- **Primário:** Estudante da Unifor.

## 4. Fluxo Principal
P1. O estudante acessa o verificador na página de uma oportunidade.
P2. O sistema apresenta o formulário e informa que a avaliação é orientativa.
P3. O estudante informa curso, semestre, PMG e proficiência linguística, conforme aplicável.
P4. O sistema valida os dados e compara os critérios com os requisitos da oportunidade.
P5. O sistema apresenta o resultado por critério, ressalva de que não garante aprovação e opções de manifestação de interesse ou candidatura oficial.

## 5. Checklist de Validação
- [ ] Nome iniciado com verbo no infinitivo.
- [ ] Objetivo claro e direto.
- [ ] Atores identificados.
- [ ] Fluxo principal coerente com o objetivo.
